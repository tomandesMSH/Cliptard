# Cliptard - Clipboard manager

cheap recreation of the Windows 11 clipboard history.

dedicated to my friend, and others who have to deal with Windows breaking stuff all the time.

## how to use

- press **Alt+V+C** to open your clipboard history
- "Clear all" wipes the list
- click outside the box, or hit escape, to close it

## running it

first time you run it, it'll ask if you want it to start automatically with
Windows. say yes if you want it always running in the background.

## running it again while it's already open kills the process instead.

it doubles as an on/off switch, aint that cool😎
